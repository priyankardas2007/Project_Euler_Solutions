## 📖 About

This repository contains my solutions to **Project Euler** problems in **JavaScript** and **Python**.

Project Euler is a collection of challenging mathematical and programming problems that require logical thinking, mathematical insight, and efficient algorithms.

The goal of this repository is to:

- 🧠 Improve problem-solving skills
- ⚡ Learn optimization techniques
- 📚 Practice algorithms and mathematics
- 💻 Write clean and efficient code in JavaScript and Python

## 🚀 Running Solutions

Clone the repository

```bash
git clone https://github.com/your-username/project-euler-solutions.git
```

Go to the project

```bash
cd project-euler-solutions
```

### JavaScript

```bash
node solution.js
```

### Python

```bash
python solution.py
```

> Depending on your installation, you may need to use `python3` instead of `python`.
